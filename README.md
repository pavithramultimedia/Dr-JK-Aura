# 🎂 Dr-JK-Aura

An interactive birthday surprise website dedicated to **Dr. J.K.**, built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎉 Animated birthday experience
- 🎵 Background music
- 📸 Memories gallery
- 🎁 Gift unlocking scene
- 🔐 Password-protected sections
- 💖 Beautiful transitions and animations
- 📱 Responsive design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Dr-JK-Aura/
├── assets/
│   ├── audio/
│   ├── images/
│   └── videos/
├── css/
├── js/
└── index.html
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/pavithramultimedia/Dr-JK-Aura.git
```

2. Open the project folder.

3. Open **index.html** in your browser.
